Read paper.md and DATA_SOURCES.md before drawing conclusions. The two-checkpoint theorem is for monotone finite-grid scores, two fixed caps, an ambiguity class consisting of all joint laws with fixed means, and a strict interior loss tolerance. Do not generalize the theorem to arbitrary multistage or known-run policies. The numerical multistage solver certifies feasible bounds rationally, not global optimality. No demonstrated real-world speedup, world-first status, peer review or DOI is claimed.

Reproduction: `python -m pip install -r requirements.txt`, then `python reproduce.py`. Use `--refit` to rerun the floating multistage solver. Original result files should be preserved.
