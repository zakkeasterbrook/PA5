Predictive Atom 5

Decision-certified key–value cache retrieval for efficient AI inference.

By Zakk Easterbrook · November 24, 2026 · Apache-2.0

View the GitHub projectRead the proofRead the audit

Preliminary, AI-assisted research. Not peer-reviewed. The theorem is for a restricted readout in exact real arithmetic. The prototype has a documented finite-precision counterexample; an optional mitigation is experimental.

Research question

Can an attention calculation establish its winning decision before reading every original key and value? PA5 uses block centroids, analytic residual bounds, progressive retrieval, a strict decision-margin test, and a dense fallback. Original KV remains stored.

94.5%Logical cache reads avoided on concentrated synthetic attention
4.92×CPU speed ratio on that favorable geometry

524,288Largest synthetic context evaluated

CPU figures exclude cache construction and do not measure physical DRAM traffic, GPU performance or end-to-end LLM acceleration. Random and tied workloads experienced slowdowns.

Reproduce and evaluate

Clone the repository and install its pinned NumPy dependency. The verifier preserves original evidence, checks archived hashes and repeats the tests in a temporary directory.

git clone https://github.com/zakkeasterbrook/PA5.git
cd PA5
python -m pip install -r requirements.txt
python reproduce.py
